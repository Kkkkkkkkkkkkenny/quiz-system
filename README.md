# 知识点问答系统

一个通用的卡片式问答系统，支持加载外部题目数据集，适用于各种知识点的复习与自测。

---

## 📖 使用指南

### 快速开始

```bash
cd quiz-system
server/server.py
```

浏览器打开打印的地址（本机 `http://localhost:8080`，局域网设备用 `http://192.168.x.x:8080`）。

也可以直接用 Python 自带服务器：

```bash
cd quiz-system
python3 -m http.server 8080
```

---

### 🎯 基本操作

| 操作 | 方式 |
|------|------|
| **显示答案** | 点击「显示答案」按钮，或按 `空格` / `回车` |
| **下一题** | 点击「下一题」按钮，或按 `→` 方向键（已显示答案后按 `空格` 也可） |
| **上一题** | 点击「上一题」按钮，或按 `←` 方向键 |
| **随机一题** | 点击「随机」按钮 |

操作流程：看问题 → 自己思考 → 按空格显示答案核对 → 再按空格进入下一题

### 🔗 URL 快捷方式

可以直接通过链接打开指定题库，方便分享或书签收藏：

| 用途 | 示例链接 |
|------|---------|
| 按数据集 ID 加载 | `http://localhost:8080/?set=ds-stack-queue` |
| 直接加载文件 | `http://localhost:8080/?file=data/demo-english.json` |
| 加载远程文件 | `http://localhost:8080/?file=https://example.com/题.json` |

参考 `datasets.json` 中每个数据集的 `id` 字段来使用 `?set=` 参数。

## 🛠 创建自己的题库

### 方法一：完整注册（推荐）

**第 1 步：** 在 `data/` 目录下新建 JSON 文件（可直接复制 `data/template.json` 修改）。

**第 2 步：** 在 `datasets.json` 中添加一条记录：

```json
{
  "id": "my-quiz",
  "file": "data/my-quiz.json",
  "title": "我的题库",
  "subject": "分类名",
  "description": "简短说明"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | 是 | 唯一标识，用于 `?set=` 参数 |
| `file` | 是 | JSON 文件路径 |
| `title` | 是 | 下拉菜单中显示的名称 |
| `subject` | 否 | 用于分组，同一分类的题库在下拉菜单中归为一组 |
| `description` | 否 | 备用字段 |

**第 3 步：** 刷新页面，下拉菜单中即可选择新题库。

### 方法二：快速测试（无需注册）

不修改 `datasets.json`，直接 URL 加载：

```
http://localhost:8080/?file=data/你的文件.json
```

## 💡 常见问题

**为什么需要 HTTP 服务器？为什么不能直接双击打开 HTML？**

因为系统通过 `fetch` 加载外部 JSON 文件，浏览器的安全策略限制 `file://` 协议下的跨文件请求：

```bash
server/server.py                # 方案一：自带服务器模块
python3 -m http.server 8080     # 方案二：Python 自带
npx serve .                     # 方案三：Node.js
```

关于网络部署的原理（局域网访问、NAT 穿透、Tailscale 组网等），详见 [server/原理.md](server/原理.md)。

**下拉菜单里没有看到我的新题库？**

检查 `datasets.json` 格式是否正确（注意 JSON 不能有多余的逗号），以及 `file` 字段指向的路径是否正确。

**如何删除某个题库？**

从 `datasets.json` 中移除对应条目即可，数据文件本身可以保留。

**进度数据存在哪里？**

仅存在于当前浏览器的内存中，刷新页面后重置。
