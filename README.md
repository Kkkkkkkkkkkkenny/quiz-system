# 408 数据结构 · 知识点问答系统

基于 408 考研数据结构第三章（栈、队列和数组）的知识点问答工具，帮助巩固概念记忆。

## 功能

- 卡片式问答：查看问题 → 自行回忆 → 点击显示答案核对
- 进度追踪：进度条 + 已掌握 / 待复习计数
- 导航切换：上一题、下一题、随机跳转
- 键盘快捷键：
  - `空格` / `回车` — 显示答案
  - `←` `→` — 切换题目

## 快速开始

项目为纯静态页面，使用任意 HTTP 服务器启动即可：

```bash
cd quiz-system
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`

## 项目结构

```
quiz-system/
├── index.html   # 主页面
├── style.css    # 样式
├── app.js       # 逻辑
├── data.json    # 35 道问答题数据
└── README.md
```

## 数据来源

知识点提纲来自 408 考研数据结构教材，答案部分由项目作者补充整理。
