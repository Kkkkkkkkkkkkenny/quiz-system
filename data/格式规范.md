# 题库数据格式规范

## 文件结构

每个题库是一个独立的 `.json` 文件，放置于 `data/` 目录下。

### 顶层结构

```json
{
  "title": "科目名称",
  "subtitle": "副标题（可选）",
  "questions": [
    { "id": 1, "topic": "章节", "question": "?", "answer": "!" }
  ]
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | string | 是 | 页面顶部显示的大标题 |
| `subtitle` | string | 否 | 标题下方的副标题 |
| `questions` | array | 是 | 题目列表，至少 1 题 |

### 题目对象

```json
{
  "id": 1,
  "topic": "栈",
  "question": "栈的定义是什么？",
  "answer": "栈（Stack）是只允许在一端进行插入或删除操作的线性表。"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | number | 是 | 题号，从 1 开始递增 |
| `topic` | string | 否 | 章节/主题分类，会显示在蓝色标签上 |
| `question` | string | 是 | 问题内容 |
| `answer` | string | 是 | 答案内容 |

### id 和 topic 的规则

- `id` 从 1 开始，**连续递增**即可，不要求严格连续（如 1, 2, 3 也可以 1, 3, 5），但不能重复
- `topic` 如果不填或填空字符串，标签显示为"通用"

## 答案格式

答案支持 4 种格式：

### 普通段落

直接写文字，每段之间空一行：

```json
"answer": "第一段内容。\n\n第二段内容。"
```

### 无序列表

用 `- ` 开头：

```json
"answer": "- 第一项\n- 第二项\n- 第三项"
```

### 有序列表

用 `数字. ` 开头：

```json
"answer": "1. 第一步\n2. 第二步\n3. 第三步"
```

### 代码块

用三个反引号包裹：

````json
"answer": "操作步骤：\n```\nif (top == -1) 下溢;\nx = S.data[top--];\n```"
````

注意：**三个反引号必须单独成行**，否则不会被识别为代码块。

### 混合示例

```json
"answer": "实现方式有两种：\n\n1. 顺序存储\n   - 优点：随机访问快\n   - 缺点：插入删除慢\n\n2. 链式存储\n   - 优点：插入删除快\n   - 缺点：不支持随机访问"
```

注意：`- ` 和 `数字. ` **必须放在行首**（缩进的不会识别为列表项，但没关系，缩进的会按段落显示）。

## 格式校验清单

创建 JSON 文件后，用以下命令检查格式是否正确：

```bash
python3 -m json.tool data/你的文件.json
```

如果输出的是格式化后的 JSON（而不是报错），说明格式正确。

常见错误：

| 错误 | 原因 | 修复 |
|------|------|------|
| `Expecting ',' delimiter` | 某行有未转义的双引号 | 检查答案文本中的 `"` 是否应为 `\"` |
| `Expecting value` | JSON 文件为空 | 检查文件内容 |
| `Extra data` | 有多个 JSON 对象 | 确保整个文件只有一个根对象 |

## 完整示例

最小可用的题库文件：

```json
{
  "title": "我的题库",
  "questions": [
    {
      "id": 1,
      "topic": "第一章",
      "question": "这是第一题？",
      "answer": "这是答案。"
    },
    {
      "id": 2,
      "topic": "第一章",
      "question": "这是第二题？",
      "answer": "- 选项A\n- 选项B\n- 选项C"
    }
  ]
}
```
